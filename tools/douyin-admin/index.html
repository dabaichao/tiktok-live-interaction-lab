高级备用：手动提供 Cookie
  1. 在 Chrome 或 Edge 打开 抖音网页版，登录你自己的账号并进入直播间。
  2. 按 F12 打开开发者工具，选择 Network（网络），然后刷新直播间。
  3. 选中发往 live.douyin.com 的请求，打开 Headers（标头）→ Request Headers（请求标头），复制 Cookie 字段的值。不是 Response Headers 中的 Set-Cookie，也不需要复制整段请求。
  4. 回到此处，粘贴到密码框并点击连接。需要包含 sessionid、sessionid_ss 或 sid_tt 等登录字段；填写不代表登录仍有效。

Cookie 等同登录凭证，请勿发送到聊天、截图或提交到仓库。有效格式的登录字段会在本机加密保存，输入成功后清空密码框；重启自动恢复，退出账号才清除。平台到期或拒绝登录时需重新扫码，暂时没有礼物事件不代表失效。此功能是本机网页登录助手，不是抖音官方开放平台 OAuth 授权。
