# 猜词有效性规则

游戏按本轮核心答案的实际字符数接收猜词，不固定为两字：答案两字收两字，三字收三字，四字收四字。

- 中文局只接受完整的对应字数汉字词，忽略首尾空白。不从长句中截取词，不删除数字、标点、表情或内部空格来拼出猜词。
- 字数按 Unicode 字符计数，生僻汉字不因 UTF-16 编码而计为两个字。
- 例：答案「苹果」时，「香蕉」「 水果 」有效；「我猜苹果」「苹果！」「苹1」「苹 果」无效。
- 在语义计算、玩家登记、有效猜词计数及榜单更新之前校验。普通聊天仍留在数据源事件流，不计入游戏，不弹出“未计入榜单”提示。
- 不添加用户冷却或刷词限制；同一个用户连续发送合规词仍可参与。`!hint` / `!skip` 指令不受字数限制。
- 点赞词、本地补足词从对应字数词池选择。礼物 AI 请求携带 `exactLength`，回包及最终入榜再次校验；无合规候选时不会用错字数词或答案强行补齐。异步生成结果不能跨局入榜。
- 词典收录要求仍由 `allowUnknownInputs` 控制，字数匹配并不绕过该设置。

测试使用隔离事件与模拟模型响应，不向实际直播间或实时榜单注入测试数据。
