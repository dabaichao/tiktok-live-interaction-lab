# 手机直播 UI 对标实现

依据用户提供的《语义猜词_UI对标评审与开发建议》及三张参考图，采用暖粉 / 奶白 / 酒红的业务画面，不复制平台外壳。保留此前要求的顶部 10% 空白。

- 设计画布 1080×2340（9:19.5），等比适配，顶部 234px、底部 180px 为直播覆盖安全区。
- 375 / 390 / 393 / 430px 手机宽度验证。390×844 下双字猜词约 18px、词性约 40px、答案字数约 17px、倒计时约 24px。长词单行省略，昵称截断。
- 顶部仅保留局数、倒计时、提示解锁进度、词性与答案字数；移除常驻线索行、阶段名称、百分比及连接状态，腾出空间放大词性/字数。真实提示仍在解锁时短暂弹出，后端提示逻辑和自动重连保持不变；连接诊断在运营后台查看。
- 猜词榜固定前14条，按服务端关联度排序；最新猜词另行展示。积分榜前20名，Top3 使用独立底色与标识，普通名次紧凑排列。
- 相似度视觉分级：<40%、40–70%、70–90%、≥90%、精确命中。最后30秒预警，最后10秒轻呼吸。
- 卡片入榜沿用事件总线；榜单保留原卡片和头像，新增卡片短距离入场、名次变化平滑移动、积分在780ms内渐变至真实数值。重复的同值快照不重播动画。
- 礼物在榜单下方固定区域单条展示，不覆盖猜词榜和积分榜；入场360ms、退场260ms，同用户同礼物连送在原卡片累计数量，高价值礼物仅改变配色和扫光、不扩大面积。支持减少动态效果。新版状态与验收详见 `emotion-ui-acceptance.md`。
- 底部原玩法/统计卡片改为纯空白贴图区，保持原位置、1044×112px 设计尺寸、底色与边框。无文字、图标或统计，提示浮层及结算遮罩避开此区域；点赞、礼物生成、加时和计分逻辑不变。
- “本轮时间到”使用画布正中心的大字提醒：约 0.3 秒放大入场、轻回弹落定、停留、缩小淡出，完整 2.4 秒；单次局部光晕，不闪屏或持续抖动。结算/新局到达立即清除，不延迟服务端流程，同局重复事件不叠加，减少动态效果时静态展示后自动消失。
- 结算卡显示真实赢家、奖励、相似度奖、助攻、下一局倒计时；无人猜中也揭晓答案。未产生的奖励显示无奖励，不伪造。
- 主播共享画面无法识别每位观看者身份，使用“最近聊天参与者”的排名高亮，避免给所有观众展示同一个“我的排名”。

## 数据协议

- 词典概念支持可选 `partOfSpeech: { "zh-Hans": "名词", "en": "noun" }`；未填写时显示“猜词挑战”。内置苹果、游艇补充真实词性。
- `round.partOfSpeech`：当前语言词性；`round.revealedAnswer`：仅 SETTLEMENT 状态提供。
- `timeline.unlockedHints` / `hintLimit` / `nextHintAt`：恢复真实已解锁提示、展示下一条倒计时。
- `ROOM_SNAPSHOT.lastSettlement`：断线重连后恢复上一局与当前结算展示。
- `room.giftWordsMultiplier` / `giftExtraTimeMs`：礼物规则来自后台配置。未配置的数据不以参考图倍率替代。

## 验证

`npm test` 与 `npm run build`。浏览器隔离验收脚本：

```powershell
# PLAYWRIGHT_MODULE 可指向本机已有 Playwright 的 index.mjs；未设置则使用本地安装的 playwright。
node tools/verify-live-layout.mjs
```

该入口运行 `verify-emotion-ui.mjs`，使用独立页面、不连接真实直播间或大模型；断言已适配手机布局、单条礼物停靠、500笔礼物突发、庆祝优先级、减少动态效果与演示网络隔离。截图写入临时目录 semantic-emotion-qa。2026-09-17本次只执行了单元测试、构建及资源检查，未重新执行浏览器视觉验收。

## 本地视觉演示

在浏览器打开 `/test-word-game/?demo=showcase` 可观看一轮完整的虚拟互动：提示解锁、猜词卡片入榜、点赞词、礼物助力、最后 10 秒、中央超时提醒和真实结构的结算卡会按时间自动演示。也可使用 `demo=gift`、`demo=timeout` 或 `demo=settlement` 直接查看单个状态。该参数只在页面端注入演示事件，不连接真实直播或模型。

新增 `/test-word-game/?demo=motion&motion=full`：每15秒循环展示猜词入榜、连送合并、普通/高级礼物、积分增长、名次反超及突发礼物。此处积分变化仅为画面演示，不代表真实游戏即时发奖规则。

直播画面默认开启动效；`motion=reduced` 或 `lowEffects=true` 关闭，`motion=auto` 跟随系统减少动态效果设置。顶部10%和底部贴图空白不变。更新时只刷新独立游戏页面，不要刷新承载Webcast桥接的整个抖音后台/分屏页。
